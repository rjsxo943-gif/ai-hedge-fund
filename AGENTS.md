# Project policy

- First principle: no extra spending beyond the owner's existing ChatGPT Pro $100 subscription.
- Use ChatGPT-authenticated Codex CLI for inference and free public market data.
- Never fall back to paid model APIs, Financial Datasets, x402 payments, paid cloud compute, or purchased Codex credits.
- On quota, authentication, or free-data failures, stop with an actionable error. Do not enable a paid alternative.
- A paid exception requires a concrete explanation of why the free path cannot achieve the task and the owner's explicit decision on that exception.
- Keep credentials, account details, personal portfolios, downloaded datasets, and generated reports out of Git. The fork is public.
- This first version is latest-data research and portfolio proposals only. Do not present Yahoo snapshots as point-in-time backtest data or execute real broker orders.
- Run the no-cost tests and relevant upstream math tests before publishing changes. Do not run paid integration tests.
